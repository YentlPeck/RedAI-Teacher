# Security policy

This is a personal research project, maintained on a best-effort basis. Only the latest version on the `main`
branch is supported.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately instead:

1. Go to the [Security tab](https://github.com/YentlPeck/RedAI-Teacher/security) of this repository.
2. Click **Report a vulnerability** and describe the problem and how to reproduce it.

I will reply as soon as I can. Thank you for reporting responsibly.
