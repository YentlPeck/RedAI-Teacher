# The teacher's knowledge base

Lessons, game facts, route steps and speedrun statistics used to produce advice.
[`KB.md`](KB.md) is the generated lesson collection; [`parts/`](parts/) holds the
individual lesson chapters. The JSON files supply structured game facts, map
connections, bot routes, statistics and the step-by-step guide.

The rebuild scripts are not included in this public copy. Game-data attribution
and licensing are explained in [`NOTICE.md`](../NOTICE.md).
