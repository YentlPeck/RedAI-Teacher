# Teacher advice and game-state helpers

The deterministic teacher and its supporting tools:

- [`advise.py`](advise.py): answers questions and recommends the next action.
- [`read_state.py`](read_state.py): reads game state for the teacher.
- [`walkable.py`](walkable.py): navigation and walkability helpers.
- [`r18_guide.py`](r18_guide.py): builds the current guide step and button suggestions.
- [`settings.py`](settings.py): paths and environment-variable configuration.
- [`extract_game_facts.py`](extract_game_facts.py): extracts game facts from the external disassembly.

The other numbered modules contain advice refinements, checks and test helpers.
